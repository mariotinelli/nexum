# Skills (Estrutura plural)

Pasta reservada para skills no padrao plural do OpenCode.

No fluxo com Laravel Boost, skills customizadas devem permanecer em:

- `.ai/skills/`

As skills instaladas/geradas pelo Boost sao refletidas em:

- `.agents/skills/`

Use esta pasta para eventual consolidacao futura, conforme estrategia de migracao definida pelo time.
