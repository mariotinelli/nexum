# Harness

## Preservar status das issues ao publicar requisitos
No Project Flow do Nexum, aprovar um requisito autoriza sua descrição, mas não altera o status da issue para Approved. Publique somente os campos expressamente autorizados e preserve o status atual; mudança de status exige instrução explícita separada do usuário.
